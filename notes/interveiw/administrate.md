# Administrate


## Second Round Interview Q/A

### Say I were to pick up a feature request ticket, can you walk me through what the process would be for me closing that ticket and getting that work deployed to production?

Sounds all good except the part where there is need for extra acceptance


### What is the one thing you would change at this company?

Old guard are feature factory; pumping out features all the time without care for quality.

New people want to change this to increase stability.

### Do you have tests? What is the coverage? Are tests added as part of each MR?

Yeah, every MR requires tests. All legacy code that do not have tests are added only when a feature touches it.


### What is you deployment process? How often do you deploy?

Seems like a quick turnaround.


### Version control setup?

GitHub


### Is there a standardised development environment and how quickly can a dev setup one locally? Docker?

Cloud based dev env. Only supports VSCode (ASK MORE ABOUT THIS).


### How do engineers collaborate? Design meetings, pair programming etc.

Design meetings are ad hoc, pair programming are not done often.


### What OS do devs use?

Only MacOS, they are keen on standardisation of all equipments and environments.


### How often do you and your devs do overtime?

Never, but a seasonally on call rota is being produced
